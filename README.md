## ✈️ 2. Aerial Vehicle Detection  


An ML-powered system to detect and classify aircraft as Civilian, Military, or UAV with high accuracy.
 
---
 Features
- Built large dataset of 60,000+ aircraft images.
- Preprocessing pipeline using OpenCV + TensorFlow.
- EfficientNet-based classifier (90% accuracy).
- Full-stack app with React frontend, Node.js backend, and MongoDB database.
---
 Tech Stack
- ML: TensorFlow, OpenCV, EfficientNet
- Frontend: ReactJS
- Backend: Node.js, Express
- Database: MongoDB
- Hardware: NVIDIA DGX A100 GPU
